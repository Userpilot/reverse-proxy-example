Userpilot Proxy Test

Open DevTools → Network. Confirm the SDK script loads from /sdk/latest.js and the events websocket opens to /userpilot/websocket — neither request should go to a userpilot.io domain directly.

The SDK opens the events socket as wss:// against whatever host:port endpoint below points to, regardless of this page's own protocol — so endpoint must point at nginx's TLS port (8443, see README "Local test with TLS"), but this page itself can still be loaded over plain HTTP.
